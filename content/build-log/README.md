# Build log

`<yyyy>-w<ww>.md` posts here are written every Monday by `npm run build-log`
(`.github/workflows/build-log.yml`): an AI summary of the previous week's real
commits across the `portfolio`-tagged repos and this site's repo. They are published
at `/log`, `/log/<slug>` and `/log/rss.xml`, and added to the AI assistant's
knowledge index.

You can edit a post by hand. Keep the frontmatter valid: the build checks it.
